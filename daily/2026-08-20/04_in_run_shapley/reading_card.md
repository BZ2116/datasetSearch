# 论文阅读卡片：In-Run Data Shapley

## 基本信息

- **论文：** Data Shapley in One Training Run
- **状态：** ICLR 2025，前沿补充
- **链接：** https://arxiv.org/abs/2406.11011
- **类型：** 数据价值 / 单次训练归因

## 归因对象

特定一次训练运行中，每条数据对训练过程和目标效用的累计贡献。

## 方法

将训练过程分解为逐步更新，对每次更新估计 Shapley contribution，再沿训练过程累积，避免传统 Shapley 的大量子集重训。

## 主要价值

能面向特定目标模型，而不是只估计学习算法平均行为；适合研究训练过程中数据价值随阶段变化的情况。

## 边界

实现和验证复杂，仍依赖效用函数、采样和近似假设；不能把单次运行分数当作普遍因果结论。
