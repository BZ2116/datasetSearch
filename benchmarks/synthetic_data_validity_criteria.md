# 合成数据有效性判定表

## 一、核心区分

| 情况 | 数据量是否增加 | 有效能力覆盖是否增加 | 能否称为有效增强 |
|---|---:|---:|---|
| 原样复制 | 是 | 否 | 否，只是数量 baseline |
| 表面改写但语义/答案不变 | 是 | 可能增加表达覆盖 | 只有未见表达表现提升时才算 |
| 实体/数值替换且 verifier 通过 | 是 | 增加实例覆盖 | 只有未见实体/数值提升时才算 |
| 增加约束且任务可解 | 是 | 可能增加难度覆盖 | 需未见约束表现提升 |
| 反事实变体正确 | 是 | 增加条件敏感性 | 需反事实评测提升 |
| 多步组合且每步可验证 | 是 | 增加结构覆盖 | 需未见组合表现提升 |
| reasoning 正确且 verifier 通过 | 是 | 可能增加过程监督 | 需过程/最终能力提升 |
| 生成失败或标签错误 | 是 | 否 | 否，必须进入失败集 |

## 二、通过标准

一类增强只有同时满足以下条件，才标记为“有效”：

1. 固定最终训练样本数、训练 token、模型、batch size、训练步数和评测集；
2. 相对原始重复 baseline，在至少一个未见分布 split 上提升；
3. 提升不完全由训练域指标驱动；
4. 语义保持率或标签一致率达到预设门槛；
5. 自动 verifier 通过率达到门槛，失败样本已完整记录；
6. 与评测集无 exact 或 near duplicate 污染；
7. 多随机种子结果方向一致，并报告 95% bootstrap CI；
8. 人工抽检未发现系统性误标或不可解任务。

## 三、结果分类

| 结果 | 解释 |
|---|---|
| 未见分布提升，数据质量通过 | 真正有效增强 |
| 只有训练域提升 | 可能是记忆/过拟合，不能称为有效泛化 |
| 数据覆盖增加但模型不提升 | 数据层有新增，模型收益尚未证明 |
| verifier 通过率低 | 生成流程失败，不能用于能力结论 |
| 复制组与增强组相当 | 增强可能只增加数量，没有产生额外能力 |
| 增强组下降 | 可能存在语义漂移、难度过高或错误 reasoning |
